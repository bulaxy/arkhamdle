# Arkhamdle

A modern, "vib-coded" wordle-style game collection for the Arkham Horror: The Card Game community.

## 🌟 About the Project

Arkhamdle is a passion project built with a "vib-coded" philosophy—focusing on smooth interactions, thematic aesthetics, and a premium experience for Arkham Horror fans. It features multiple guessing games inspired by popular word games, all themed around Arkham Horror cards.

Play it now at: **[arkhamdle.com](https://arkhamdle.com)**

## 🎮 Available Games

- **Wordle / Classic Mode** - Guess the Arkham Horror card in 6 tries
- **Pic Guesser** - Identify cards from their artwork
- **Investigatordle** - Guess Arkham Horror investigators with clues
- **Story Guesser** - Identify cards from their flavor text
- **Trait Guesser** - Find cards matching specific traits
- **Flavour Guesser** - Guess cards from card type and traits
- **Encounter Guesser** - Identify encounter cards with visual hints
- **Trivia Guesser** - Answer questions about Arkham Horror cards

## ✨ Features

- 🎨 Customizable difficulty and game settings
- 📦 Pack-based card filtering
- 🌐 GitHub Pages redirect for easy access
- 💾 Persistent settings using local storage
- 🔄 Global pack filters across all games
- ♿ Accessibility-focused design

## 📊 Data Source

All card data and information are sourced from the [ArkhamDB API](https://arkhamdb.com/api/doc) and the [arkhamdb-json-data](https://github.com/Kamalisk/arkhamdb-json-data) repository. We are grateful to the ArkhamDB team and contributors for their incredible work in maintaining the community's primary data resource.
